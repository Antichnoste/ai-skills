# AI Skills

A personal collection of reusable skills for working with AI assistants.

The repository contains workflows that help me use AI more effectively for learning, programming, machine learning, and technical projects.

## Skills

* **algorithm-tutor** — helps understand and derive algorithmic solutions step by step.
* **dataviz-skills** — helps create clear and useful data visualizations.
* **explain-ml-step-by-step** — explains ML and statistics concepts from intuition to formulas and examples.
* **math-to-ml** — connects mathematical concepts with their practical use in machine learning.
* **resume-project-writer** — turns technical project descriptions into concise resume bullet points.

## Structure

Each skill is stored in its own directory:

```text
skills/
├── algorithm-tutor/
│   └── SKILL.md
├── dataviz-skills/
│   └── SKILL.md
├── explain-ml-step-by-step/
│   └── SKILL.md
├── math-to-ml/
│   └── SKILL.md
└── resume-project-writer/
    └── SKILL.md
```

## Goal

Keep only skills that are genuinely useful, reusable, and improve the way I work with AI.
